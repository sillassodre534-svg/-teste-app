# Calculadora de Média do Aluno

Projeto desenvolvido em Python para calcular a média aritmética de duas notas e determinar se o aluno foi aprovado ou reprovado.

## 🛠️ Tecnologias Utilizadas
- **Python**

## 🚀 Como Instalar e Executar
1. Certifica-te de que tens o Python instalado.
2. Abre a pasta do projeto no VS Code.
3. Executa o comando no terminal:
   ```bash
   python app.py
